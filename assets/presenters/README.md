# Presenter portraits

Square JPEGs, displayed as 78px circles. Anything from about 300px up is plenty;
faces should be roughly centered.

Filenames are lowercase surname:

    straight.jpg  wagner.jpg  honomichl.jpg  leiterman.jpg  cronin.jpg

To change one, replace the file and re-render. The markup in `index.qmd` is:

    <div class="presenter-portrait"><img src="assets/presenters/NAME.jpg" alt="Full Name"></div>

Keep the alt text as the person's name.

If you'd rather a different photo of yourself was used, send it to Ryan Straight
(ryanstraight@arizona.edu) and it'll be swapped.
